# CRCC Church Office Management System

## About the Project

The **CRCC Church Office Management System** is a MySQL database project designed to support the data management needs of Christ the Rock Christian Church.

This project provides a centralized database structure for organizing and storing information related to church office operations, ministry activities, announcements, events, and other church-related records.

## Project Information

- **Project Name:** CRCC Church Office Management System
- **Database Name:** `crcc_church_office`
- **Database Type:** MySQL / MariaDB
- **File Format:** SQL (.sql)

## Repository Contents

| File | Description |
|---|---|
| `cleaned_mysql.sql` | Contains the database structure, table definitions, and SQL records. |

## Database Features

The database is intended to support the following areas:

- Church office records management
- Ministry and activity information
- Announcement management
- Event-related records
- Storage and organization of church information

## Requirements

To import and manage this database, you need:

- XAMPP
- MySQL or MariaDB
- phpMyAdmin
- A web browser

## Installation and Setup

1. Download or clone this repository.
2. Open XAMPP Control Panel.
3. Start Apache and MySQL.
4. Open phpMyAdmin at `http://localhost/phpmyadmin`.
5. Create a database named `crcc_church_office`.
6. Select the newly created database.
7. Go to the **Import** tab.
8. Choose the `cleaned_mysql.sql` file.
9. Click **Import** or **Go** to execute the SQL file.

After successful import, the database tables and included records will be available in phpMyAdmin.
